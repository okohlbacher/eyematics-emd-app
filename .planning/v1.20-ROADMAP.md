## Phase 2 — Image
- `Containerfile`: build stage on `$BUILDPLATFORM` (SPA is arch-independent), deps stage on the target arch (`npm ci --omit=dev` → per-arch better-sqlite3/esbuild prebuilds), runtime `node:24-bookworm-slim`, `USER node`, `HEALTHCHECK`, `dist/data` (18 MB duplicate) dropped.
- State reaches the `/data` volume through baked-in symlinks (`config/settings.yaml`, `feedback/`) + `server.dataDir: /data` — zero server config code. `deploy/entrypoint.sh` seeds `/data/settings.yaml` from `deploy/settings.yaml` (parity with `config/settings.yaml` enforced by `tests/deploySettings.test.ts`).
- `scripts/container-smoke.sh`: build/pull → boot → login → API → SPA → `/data` 403 → volume contents (0600 secret) → ≤ 3 s SIGTERM stop → restart keeps the token valid. `IMAGE=`/`PLATFORM=`/`CONTAINER_CLI=` overrides.

## Phase 3 — Quadlet + docs
- `deploy/EMD.container` = Nils' unit + `UserNS=keep-id:uid=1000,gid=1000` (image runs as uid 1000; keeps `~/EMD` his), `:Z` on the volume (SELinux), `HealthCmd`/`Notify=healthy` (auto-update rollback; Podman ignores image HEALTHCHECKs on OCI images), `TimeoutStartSec=900`, **no** `EnvironmentFile` (Quadlet has no optional `-` form; the app reads no env).
- `docs/Deployment.md` (German): install, first start (default passwords!), settings on the volume, updates, backup/reset, TLS, Docker one-liner, troubleshooting. README + Konfiguration.md pointers; `_config.yml` excludes.

## Phase 4 — CI
